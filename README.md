## Sobre o Projeto

O **LingProg** é uma plataforma web informativa dedicada a reunir conteúdos sobre linguagens de programação. O site apresenta cards detalhados com as principais características de cada linguagem, incluindo número estimado de desenvolvedores, breve descrição e links para aprofundamento.

## Funcionalidades

- Layout responsivo para desktop, tablet e celular
- Animações de entrada e transições suaves via CSS
- Cards interativos com efeitos de hover específicos para cada linguagem
- Sistema de carregamento inicial (loader)
- Menu de navegação adaptável para dispositivos móveis
- Botão de retorno ao topo da página
